# Emil Kowalski Animation & Micro-interaction Skill

This skill enforces high-end UI craftsmanship, spring physics, subtle hover transitions, micro-interactions, modal backdrops, and polished component feedback inspired by Emil Kowalski's design guidelines.

## Core Principles
1. **Fluid Motion:** Every state transition should feel organic and responsive.
2. **Subtle Details:** Soft shadows, precise border highlights, and polished active states.
3. **No Heavy Lags:** Fast, GPU-accelerated Tailwind transitions (`transition-all duration-200 ease-out`).
