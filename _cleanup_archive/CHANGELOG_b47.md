# b47 — یکپارچه‌سازی و تثبیت چندمرحله‌ای

## تغییرات واقعی این انتشار
- حذف تکرارهای ناخواسته در `TasksWorkspace`: import تکراری، stateهای تکراری، مسیرهای تکراری گردش کار، modal تکراری و handler تکراری کارت.
- یکپارچه‌سازی پنل گردش کار واحد و بازگردانی علت مانع/نتیجه/اقدام بعدی هنگام بازکردن وظیفه.
- بهبود صف استثناها: تشخیص مهلت نامعتبر، نبود مسئول، مانع بدون علت، اولویت بالا بدون مهلت، مرتب‌سازی موارد پرخطر.
- گسترش تست‌های گردش کار برای انتقال‌های نامعتبر، عدم تغییر رکورد اولیه، ثبت actor/timestamp، رفع مانع، نتیجه بدون بستن، تکمیل و مرتب‌سازی استثناها.
- افزودن تست قرارداد UI که وجود مسیرهای اصلی گردش کار و نبود تکرارهای regression را بررسی می‌کند.
- همگام‌سازی نسخه در package، metadata، APP_VERSION و تست قرارداد: `0.12.21`.

## مرزهای تأییدشده
- آزمون‌های Node موجود و قراردادهای ایستا اجراشدنی‌اند.
- Build و TypeScript در این محیط به دلیل نبود وابستگی‌ها قابل تأیید نیستند.
- این انتشار ادعای اتصال واقعی ERP، اجرای SQL Server/RLS، ارسال اعلان، sync چنددستگاهی یا ممیزی تغییرناپذیر سمت سرور ندارد.
