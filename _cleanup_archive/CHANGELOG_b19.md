# CHANGELOG b19 — Geo workspace + configurable Geo RBAC

تاریخ: 2026-10-26

## مبنا و رویکرد
- مبنا: بستهٔ b18؛ تغییرات افزایشی هستند و موتور RBAC، مدل‌های مالی و state قبلی جایگزین نشده‌اند.
- نسخهٔ برنامه: `0.11.5`، شناسهٔ انتشار: `r11-cp9-b19`.

## تغییرات محصول
- صفحهٔ «هوش مکانی و مدیریت زون‌ها» به مسیر `/geo-intelligence` افزوده و از منوی اصلی قابل دسترسی شد.
- صفحه سه حالت زمینه‌ای «زون‌ها»، «تحلیل و Heatmap» و «عملیات و انتساب» دارد.
- فرم ایجاد/ویرایش زون، کد یکتا، ورود مختصات طول/عرض در ردیف‌های مجزا، بستن حلقه، اعتبارسنجی polygon و پیش‌نمایش شکل هندسه اضافه شد.
- ذخیرهٔ هندسه نسخه‌دار است؛ نسخهٔ قبلی بسته می‌شود و حفظ می‌شود. وضعیت زون قابل تغییر به پیش‌نویس/فعال/بایگانی است و تغییرات audit می‌شوند.
- انتساب مشتریان با آزمون point-in-polygon فقط برای مختصات معتبر و مشتریان مجاز طبق RBAC انجام می‌شود؛ سوابق قبلی با تاریخ پایان بسته می‌شوند و رکوردهای خارج از scope کاربر تغییر نمی‌کنند. از زون فعال می‌توان برای یک مشتری مجاز، وظیفهٔ پیگیری وصول در فهرست وظایف موجود با مسئول، ناظر اختیاری، مهلت و اولویت ساخت؛ اعلان از موتور همکاری فعلی عبور می‌کند.
- مجوزهای مستقل `geo.view` و `geo.manage` به ماتریس مجوزها اضافه شدند و در صفحه تنظیمات پروفایل مجوز قابل تنظیم‌اند. `geo.manage` جدا از مشاهده است؛ مجوزهای مدیریتی قبلی برای سازگاری همچنان می‌توانند مدیریت را مجاز کنند.
- همه سنجه‌های Heatmap عمداً غیرفعال باقی مانده‌اند تا اتصال و تطبیق منبع واقعی؛ هیچ KPI مکانی ساختگی نشان داده نمی‌شود.
- آزمون قراردادی جدید مسیر UI، RBAC، scope مشتری، versioning و وضعیت سنجه‌ها را پوشش می‌دهد.

## آزمون‌های واقعی این دور
- `npm test`: PASS؛ 471 assertion مجموع گزارش‌شده توسط suiteها، شامل 14 assertion قراردادی جدید برای صفحهٔ هوش مکانی.
- `node scripts/audit-actions.mjs`: PASS؛ 74 handler تغییردهنده، 74 دارای guard، صفر مورد بدون guard در ممیزی ایستا.
- `npm run audit:contracts`: PASS؛ بررسی ایستای 9 فایل SQL، 46 جدول، 44 جدول tenant-scoped، 44 هدف RLS و 5 view موردنیاز. این بررسی اتصال/اجرای SQL Server نیست.
- TypeScript `transpileModule`: PASS از نظر syntax/transpile برای فایل‌های تغییرکرده؛ typecheck کامل محسوب نمی‌شود.

## مسدود/تأییدنشده
- تلاش `npm install --ignore-scripts --no-audit --no-fund` در این محیط تا پایان مهلت 120 ثانیه timeout شد؛ Vite و type definitions در دسترس قرار نگرفتند.
- `npm run lint`: BLOCKED به‌علت نبود `vite/client`/وابستگی‌ها.
- `npm run build`: BLOCKED؛ `vite: not found`.
- مرورگر واقعی، Safari/iOS، SQL Server runtime، Backend/API و ERP در این محیط اجرا نشدند.

## موارد باقی‌مانده
- نقشهٔ واقعی ایران، انتخاب/آزمون tile provider، ابزار رسم/ویرایش مستقیم روی نقشه، چاپ و آزمون موبایل.
- اتصال Heatmap به منابع معتبر فروش/مالی/برگشتی/وصول، freshness، attribution تولیدکننده و cross-filter؛ ثبت نتیجهٔ نهایی/مبلغ وصول/evidence و گزارش عملکرد task نیز باقی است.
- ایجاد task وصول از زون، مسئول/ناظر/مهلت، ثبت نتیجه واقعی و گزارش سلسله‌مراتبی.
- typecheck/build/lint کامل و آزمون واقعی UI؛ enforcement سمت Backend و SQL Server RLS.
