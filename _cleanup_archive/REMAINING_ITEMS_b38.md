## مواردی که در کد قابل تکمیل مستقل از سرویس بیرونی نیستند
- [ ] **ERP زنده و Redis:** نیازمند endpoint، روش احراز هویت، قرارداد payload، دسترسی شبکه و استقرار امن سمت سرور. فعلاً فقط adapter contract و cache حافظه‌ای وجود دارد؛ اطلاعات مالی زنده در UI نشان داده نمی‌شود.
- [ ] **SQL Server و RLS واقعی:** نیازمند محیط آزمایشی SQL Server و اجرای migrationها؛ تست ایستای متن SQL معادل اجرای دیتابیس نیست.
- [ ] **RBAC امنیتی سمت سرور:** نیازمند API و هویت قابل اعتماد سمت سرور؛ helper سمت کلاینت مرز امنیتی نیست.
- [ ] **TSP و ETA واقعی:** نیازمند provider نقشه/مسیریابی، مختصات معتبر و قواعد زمان سفر. گروه‌بندی منطقه‌ای به تنهایی route optimization نیست.
- [ ] **SLA escalation پس‌زمینه:** نیازمند worker یا scheduler پایدار؛ محاسبه SLA و guard در زمان ایجاد به‌تنهایی تضمین پایش نیست.
- [ ] **Build/TypeScript و تست مرورگر:** وابستگی‌ها در محیط موجود نصب نشدند (نصب بدون lockfile timeout شد). لازم است در محیط دارای دسترسی بسته‌ها اجرا شود و سپس تست واقعی UI/IndexedDB انجام شود.
- [ ] **تکمیل همه‌ی فرم‌های اختصاصی:** فرم‌های مبتنی بر `DynamicFormRenderer` منشن عمومی دارند؛ فرم‌های اختصاصی که renderer را مصرف نمی‌کنند باید جداگانه بررسی شوند.
- [ ] **پیش‌نمایش context و ناوبری موجودیت‌ها در چت:** مرجع entity در پیام ذخیره می‌شود، اما کارت پیش‌نمایش مالی زنده و لینک جزئیات همه‌ی انواع entity هنوز کامل نیست.
- [ ] **Virtualization و چهار حالت UI سراسری:** نیازمند ممیزی صفحه‌به‌صفحه و اجرای مرورگر؛ نباید صرف وجود EmptyState/Skeleton در پروژه را به‌معنای پوشش همه صفحات دانست.
- [ ] **Supabase / Zod+React Hook Form:** عمداً مهاجرت یا وابستگی جدید بدون تصمیم زیرساختی، نصب، و آزمون انجام نشده است. ابتدا باید تصمیم معماری و طرح انتقال داده/RLS تصویب شود.

## شرط بستن پروژه
این موارد فقط پس از فراهم شدن محیط و اجرای آزمون‌های واقعی می‌توانند بسته شوند. هیچ endpoint، کلید، داده مالی، ETA یا نتیجه‌ی اتصال ساخته‌سازی نشده است. ERP مرجع رسمی فاکتور و حسابداری باقی می‌ماند.
